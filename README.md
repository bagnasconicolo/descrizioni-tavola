# Descrizioni Tavola

Descrizioni definitive dei campioni del **Piccolo Museo della Tavola Periodica "Primo Levi"**.

`descrizioni.json` contiene, per ciascun campione già revisionato, il codice oggetto, il numero atomico dell'elemento associato, il titolo e la descrizione curatoriale.

Struttura di ogni voce:

```json
{
  "codice": "H-001-1",
  "numero_atomico": 1,
  "titolo": "...",
  "descrizione": "..."
}
```

395 campioni al momento dell'ultimo aggiornamento (26 ottobre 2026): tutti i campioni pubblici con la descrizione rivista.
